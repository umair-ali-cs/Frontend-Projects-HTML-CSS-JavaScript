# Frontend-Projects-HTML-CSS-JavaScript
A collection of frontend projects built using HTML, CSS, and JavaScript, focusing on UI design, DOM manipulation, and interactive web features.

## 🔗 Live Demos
- [Graph Plotter (2D VisualMath)](https://umair-ali-cs.github.io/Frontend-Projects-HTML-CSS-JavaScript/Graph%20Plotter/)
- [Chess Game](https://umair-ali-cs.github.io/Frontend-Projects-HTML-CSS-JavaScript/Chess/)

## 📂 Projects
| Project | Description |
|---|---|
| **Chess** | Full 2-player chess game with move validation, check/checkmate/stalemate detection, and pawn promotion. |
| **Graph Plotter** | A 2D math graph plotting tool built with vanilla JavaScript. |

## 🛠️ Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6)
